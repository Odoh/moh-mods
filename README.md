# moh-mods

Mods and tooling for **Medal of Honor: Breakthrough** running on [OpenMoHAA](https://github.com/openmoh/openmohaa)
(tested with v0.82.1 on Windows 11, GOG *Allied Assault War Chest*).

No game files are included. You need your own copy of the game.

| Folder | What's in it |
|---|---|
| `maps/courtyard/` | **Courtyard**: a small town-square DM map generated by `make_map.py` |
| `maps/tallchurch/` | **Destroyed Village – Tall Tower**: a clone of `mohdm2` with the church tower 3x taller, belfry spawn, darkness while you're in the tower, and long-range bullets. `mapedit.py` is a small `.map` parser and transformer |
| `weaponkit/` | `make_weapon.py`: builds custom weapon variants (Rocket Hose, Barn Door, Grenade Hose …) from stock `.tik` files into `user-*.pk3` and writes key binds |
| `bots/` | Per-bot **personality** patch for OpenMoHAA v0.82.1 (`game.dll`) and the `bot_personalities.cfg` profiles |
| `tools/` | `extract_compilebase.py` and `fix_missing_tga.py`: workarounds that let MOHlight light big maps |
| `docs/GUIDE.md` | The full install and modding guide, including every gotcha we hit |

## Quick start

1. Install the GOG War Chest, then extract an OpenMoHAA `windows-x64` release into the game folder.
2. Weapons: `py -3 weaponkit/make_weapon.py all`, then start with
   `openmohaa.exe +set com_target_game 2 +set thereisnomonkey 1 +set developer 1 +set cheats 1 +exec weaponkit.cfg +devmap dm/<map>`
   and press G (Rocket Hose), F7, F8, F10, F11, [ or ].
3. Maps: see `docs/GUIDE.md`. They're compiled with [MOHTools](https://github.com/RaGe742004/MOHTools)
   (`Q3map.exe`, `MOHlight.exe`). The tall-tower clone needs `mohdm2.map` from MOHTools, copied to
   `maps/tallchurch/mohdm2_orig.map` (not included here).
4. Bot personalities: apply the patch to an OpenMoHAA v0.82.1 checkout:
   ```
   git clone --branch v0.82.1 https://github.com/openmoh/openmohaa
   cd openmohaa && git apply ../bots/openmohaa-v0.82.1-bot-personalities.patch
   ```
   Build the `fgame` target (VS 2022 + CMake + WinFlexBison, `-DBUILD_NO_CLIENT=1`), copy `game.dll`
   into the game folder (keep a backup of the original), and put `bots/bot_personalities.cfg` in `maintt/`.
